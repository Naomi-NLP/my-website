# Joy Olusanya — Personal Academic Website

A modern, responsive academic portfolio website for Joy Olusanya, NLP Researcher & Language Technologist.

## 🚀 Deploy to GitHub Pages

### Step 1: Create a new GitHub repository
- Go to github.com → New repository
- Name it `yourusername.github.io` (for root domain) or any name (for `/repo` path)
- Set to **Public**

### Step 2: Upload files
Upload these files to the repository root:
```
index.html
styles.css
script.js
```

### Step 3: Enable GitHub Pages
- Go to **Settings → Pages**
- Source: **Deploy from a branch**
- Branch: `main` → `/ (root)`
- Click **Save**

### Step 4: Visit your site
Your site will be live at:
- `https://yourusername.github.io` (if repo named `yourusername.github.io`)
- `https://yourusername.github.io/repo-name` (for any other repo name)

## 📁 File Structure
```
/
├── index.html      ← Main page (all sections)
├── styles.css      ← All styles & responsive rules
├── script.js       ← Canvas particles, navbar, animations
└── README.md
```

## ✏️ Customisation

**Update your social links** in `index.html`:
- Search for `linkedin.com/in/joy-olusanya` → replace with your actual LinkedIn URL
- Search for `github.com/joyolusanya` → replace with your actual GitHub username

**Update phone/email** in the Contact section.

**Add your profile photo**: Place a photo in an `/assets` folder and add an `<img>` tag to the About section.
